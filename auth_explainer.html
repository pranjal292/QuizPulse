0. What Does auth.js Actually Do? Overview

In many full-stack web applications, you would have a Node.js/Express backend with routes like /api/login, /api/quiz, etc. Because QuizPulse is a serverless static web application, auth.js acts as the client-side service layer.

It connects directly to the global db (Cloud Firestore) provided by firebase.js. If Firebase keys are not provided or if the browser is offline, auth.js automatically falls back to browser localStorage without crashing!

Viva Defense Tip: If an examiner asks "Where is your backend controller?", tell them: "Sir, auth.js is our business logic and data-access layer. It wraps all Firestore NoSQL operations and manages authentication state for teachers and students."

5. Analysis of Results (Scores & Summaries) Lines 554 – 724

calculateQuizOverviewStats(quiz) Lines 559 – 657

Powers the Teacher Studio's analytics overview. Loops through all student submissions to calculate aggregate statistics:

  • Counts: Total attempts, submitted count, in-progress count, and cheating-terminated count.
  • Score Metrics: Highest score, lowest score, and average score calculated as (totalScoreSum / scoredSubmissionsCount).toFixed(1).
  • Per-Question Accuracy Grid: Compares student responses against quiz.answerKey to reveal which questions were hardest for the class.
Viva Defense Tip: If an examiner asks: "How does the teacher see which questions were failed by the majority of the class?" Answer: "In auth.js, calculateQuizOverviewStats() tracks questionCorrectCounts[qId] across all submissions and returns a percentage per question so the teacher knows which topic needs revision."
