Syntax Cheat Sheet with Line Explanations

Every core HTML5 tag, CSS3 rule, JavaScript pattern, and Cloud Firestore query used across this project—with real code examples from the codebase and step-by-step line explanations.

1. HTML5 Structural & Semantic Elements

HTML Syntax
<header>, <nav>, <main>, <section>, <footer>
HTML Semantics
Defines the distinct structural sections of the page without relying only on generic <div> tags.
<header class="app-header"> ... </header> <main class="main-container"> <section id="tab-quizzes"> ... </section> </main> <footer class="app-footer">QuizPulse © 2026</footer>
Line-by-Line Explanation:
  • <header> Encloses the top navigation bar with the brand logo, user badge, and logout action.
  • <main> Wraps the dominant, central content of the document (excluding repeated headers and footers).
  • <section> Groups logically connected sub-screens (e.g. Dashboard view, Create Quiz view) so JavaScript can toggle them using .hidden.
  • <footer> Contains copyright info, persistent at the bottom of the page.
<form>, <input>, <label>, <button type="submit">
HTML Forms
Collects user text inputs (room code, email, passwords) with built-in browser validation.
<form id="teacher-auth-form"> <div class="form-group"> <label class="form-label" for="auth-email">Faculty Email</label> <input id="auth-email" type="email" class="input-text" placeholder="name@domain.edu" required> </div> <button type="submit" class="button button-primary">Sign In</button> </form>
Line-by-Line Explanation:
  • <form id="..."> Binds the inputs together into a single form group so pressing 'Enter' submits the data.
  • <label for="..."> Associates the label text with the input's id for accessibility and easy clicking.
  • required Browser attribute that blocks form submission if the user leaves the input blank.
  • type="submit" Triggers the form's submit event listener in JavaScript when clicked.
<input type="radio" name="..." value="...">
HTML Choice Selection
Ensures a student can pick only one answer per question by grouping options under the same 'name'.
<label class="option-label"> <input type="radio" name="question_q1" value="0"> <span>A. Queue</span> </label> <label class="option-label"> <input type="radio" name="question_q1" value="1"> <span>B. Stack</span> </label>
Line-by-Line Explanation:
  • type="radio" Circular option input where only one choice can be active at a time in a group.
  • name="question_q1" The grouping identifier. All radio inputs with this exact same name become mutually exclusive.
  • value="1" The zero-based option index stored in JavaScript when the student checks this choice.
<table>, <thead>, <tbody>, <tr>, <th>, <td>
HTML Tables
Structures tabular data (quiz list, submissions roster, question statistics).
<table class="data-table"> <thead> <tr><th>Student ID</th><th>Status</th><th>Score</th></tr> </thead> <tbody id="live-roster-tbody"> <tr><td>student101</td><td>submitted</td><td>5 / 5</td></tr> </tbody> </table>
Line-by-Line Explanation:
  • <thead> & <th> Header row describing each column in uppercase monospace font.
  • <tbody id="..."> The target table body that JavaScript dynamically wipes and populates with new <tr> rows.
  • <td> Individual table data cells displaying student ID, scores, and formatted dates.

2. CSS3 Layouts, Variables & Design Tokens

CSS Syntax
:root { --variable-name: value; } & var(--variable-name)
CSS Custom Properties
Defines global color, font, and border variables that can be reused anywhere in the stylesheet.
:root { --paper: #f1f1ec; --accent: #245c3c; --ink: #161917; } body { background-color: var(--paper); color: var(--ink); }
Line-by-Line Explanation:
  • :root Pseudo-class targeting the highest-level element (HTML), making variables accessible across the entire page.
  • --paper: #f1f1ec; Declares a custom property named --paper holding the warm parchment background hex code.
  • var(--paper) Retrieves the value of the custom property. If you change --paper in :root, the entire app updates instantly.
display: flex; justify-content; align-items; gap;
CSS Flexbox
Aligns child items horizontally in rows or vertically in columns with automatic spacing.
.app-header { display: flex; justify-content: space-between; align-items: center; gap: 16px; height: 56px; }
Line-by-Line Explanation:
  • display: flex; Transforms the container into a flex container, placing all direct children side-by-side in a row.
  • justify-content: space-between; Pushes the brand logo to the far left and the user controls to the far right.
  • align-items: center; Vertically centers items inside the 56px header bar so text and buttons line up perfectly.
  • gap: 16px; Places a clean 16px space between adjacent children without needing manual margins.
display: grid; grid-template-columns: repeat(auto-fit, minmax(...));
CSS Grid
Creates fully responsive statistic cards that automatically wrap onto new rows on mobile screens.
.stats-row { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 16px; }
Line-by-Line Explanation:
  • display: grid; Establishes a 2-dimensional grid layout system.
  • auto-fit Fits as many cards onto a single row as possible based on the container width.
  • minmax(200px, 1fr) Each card must be at least 200px wide. If more space is available, cards expand equally (1fr).
position: sticky; & position: fixed; z-index;
CSS Positioning
Pins headers and timers to the screen while students scroll through long exams.
.exam-header { position: sticky; top: 0; z-index: 50; background-color: var(--paper); } .toast-message { position: fixed; top: 16px; right: 16px; z-index: 100; }
Line-by-Line Explanation:
  • position: sticky; top: 0; Scrolls normally with the page until it hits the top (0px), then "sticks" in place.
  • position: fixed; Removes the toast from the document flow and locks it to the top-right corner of the browser viewport.
  • z-index: 100; Ensures the notification banner renders in front of all table rows, cards, and modal backdrops.
.hidden { display: none !important; }
CSS Utility Pattern
The core UI switcher class used by JavaScript to show or hide screens and modals.
.hidden { display: none !important; }
Line-by-Line Explanation:
  • display: none; Completely removes the element from visual rendering and layout calculations.
  • !important Overrides any conflicting layout rules (like display: flex or display: block) when JavaScript toggles views.

3. JavaScript: DOM Manipulation & Event Handling

JavaScript Syntax
document.getElementById("...") & querySelector("...")
DOM Selection
Finds HTML elements on the page and stores them in distinct variables for manipulation.
const examTimerDisplay = document.getElementById("exam-timer-display"); const btnSubmitExam = document.getElementById("btn-submit-exam"); const allLabels = optionsContainer.querySelectorAll(".option-label");
Line-by-Line Explanation:
  • const examTimerDisplay Stores the reference in a constant so JavaScript doesn't have to search the document repeatedly.
  • getElementById("...") Fast, single-element lookup matching the exact id attribute in the HTML.
  • querySelectorAll(".option-label") Finds all elements inside optionsContainer matching the CSS class .option-label.
createElement(), .className, .appendChild()
DOM Construction
Builds dynamic HTML nodes (like question cards or table rows) step-by-step in memory.
const cardElement = document.createElement("div"); cardElement.className = "question-card"; const textElement = document.createElement("p"); textElement.className = "question-text"; textElement.textContent = question.questionText; cardElement.appendChild(textElement); containerElement.appendChild(cardElement);
Line-by-Line Explanation:
  • document.createElement("div") Creates a brand new <div> element in memory, not yet visible on screen.
  • cardElement.className = "..." Applies CSS styles by setting the element's class attribute.
  • textElement.textContent = ... Safely sets plain text content (protects against XSS attacks by not evaluating raw HTML).
  • container.appendChild(...) Inserts the newly built card element into the live DOM tree inside the container.
addEventListener("event", function(event) { event.preventDefault(); })
Event Handling
Listens for user actions (clicks, form submissions, typing) and executes code in response.
teacherAuthForm.addEventListener("submit", async function(event) { event.preventDefault(); const email = authEmailInput.value.trim(); // Proceed with authentication... });
Line-by-Line Explanation:
  • addEventListener("submit", ...) Attaches a trigger that runs every time the form is submitted by clicking the button or pressing Enter.
  • event.preventDefault(); Stops the browser from reloading the page or sending an HTTP GET query string in the URL.
  • authEmailInput.value.trim() Reads the text typed into the input and strips unnecessary spaces from the start and end.
element.classList.add() & .classList.remove()
Class Manipulation
Adds or removes classes to show/hide views or change active button highlights.
function hideAllViews() { tabQuizzes.classList.add("hidden"); tabCreate.classList.add("hidden"); tabLive.classList.remove("hidden"); }
Line-by-Line Explanation:
  • classList.add("hidden") Adds the .hidden CSS class, causing the browser to apply display: none !important;.
  • classList.remove("hidden") Removes the .hidden class, making the tab view immediately visible to the user.

4. JavaScript: Loops, Logic & Objects

JavaScript Syntax
for (let i = 0; i < array.length; i = i + 1) { ... }
Iteration
Iterates step-by-step through an array without using arrow functions or array helper methods.
let correctCount = 0; for (let i = 0; i < questionsList.length; i = i + 1) { const question = questionsList[i]; const studentChoice = responsesMap[question.id]; const correctChoice = answerKeyMap[question.id]; if (studentChoice !== undefined && Number(studentChoice) === Number(correctChoice)) { correctCount = correctCount + 1; } }
Line-by-Line Explanation:
  • let i = 0 Initializes the loop index pointer at 0 (the first item of the array).
  • i < questionsList.length Loop condition: runs as long as i is less than the total count of questions.
  • i = i + 1 Explicit step increment, moving forward one element on each iteration.
  • correctCount = correctCount + 1 Increments the student's score if their chosen option index matches the official answer key.
JSON.stringify() & JSON.parse()
Data Serialization
Converts JavaScript objects into string text for storage/transmission, and parses text back into objects.
// 1. Converting an object to text string for saving const jsonString = JSON.stringify(quizObject); localStorage.setItem("quizpulse_quizzes", jsonString); // 2. Converting stored text back into a usable object const savedText = localStorage.getItem("quizpulse_quizzes"); if (savedText !== null) { const loadedQuiz = JSON.parse(savedText); console.log(loadedQuiz.quizTitle); }
Line-by-Line Explanation:
  • JSON.stringify(quizObject) Takes a complex JS object (with nested arrays and questions) and turns it into a formatted JSON string.
  • JSON.parse(savedText) Reads the text string and reconstructs real JavaScript arrays and objects so you can access properties like .quizTitle.
localStorage.setItem() / getItem() / removeItem()
Web Storage API
Persists data in the browser so it survives page refreshes and window reloads.
// Saves active student session in sessionStorage sessionStorage.setItem("quizpulse_student", JSON.stringify(sessionData)); // Reads saved session const studentData = JSON.parse(sessionStorage.getItem("quizpulse_student")); // Wipes session on logout or exit sessionStorage.clear();
Line-by-Line Explanation:
  • localStorage Permanent browser storage (keeps teacher logins and quiz history saved indefinitely).
  • sessionStorage Temporary tab storage. Used for student exam sessions so closing the browser purges their active attempt.
  • .clear() Completely empties all stored keys for that origin, preventing the student from resuming their attempt.

5. Asynchronous JavaScript, Timers & Cloud Firestore

Async / Cloud Syntax
async function ... const data = await ... try / catch
Asynchronous JavaScript
Pauses function execution until a network or database request completes, catching any errors safely.
async function fetchQuizByCode(orgCode) { try { if (db !== null) { const docSnapshot = await db.collection("quizzes").doc(orgCode).get(); if (docSnapshot.exists === true) { return docSnapshot.data(); } } return null; } catch (error) { showToast("Error reading database: " + error.message, true); return null; } }
Line-by-Line Explanation:
  • async function Tells JavaScript that this function performs asynchronous operations and is permitted to use the await keyword.
  • await db.collection(...).get() Pauses right at this line until Google's Firestore servers return the document over the internet.
  • try { ... } Attempts the network operations. If anything goes wrong (e.g. offline, timeout), execution jumps to catch.
  • catch (error) Catches the error gracefully and displays a friendly toast banner instead of letting the entire page crash.
setInterval(function, 1000) & clearInterval(intervalId)
Timers & Polling
Runs code periodically (countdown clock every 1 second, waiting room polling every 2 seconds).
let quizTimerId = setInterval(function() { const elapsedSeconds = (Date.now() - studentStartTime) / 1000; const remainingSeconds = totalDuration - elapsedSeconds; timerDisplay.textContent = formatTimer(remainingSeconds); if (remainingSeconds <= 0) { clearInterval(quizTimerId); executeAutoSubmission("timer_expired"); } }, 1000);
Line-by-Line Explanation:
  • setInterval(..., 1000) Executes the inner function repeatedly every 1,000 milliseconds (exactly 1 second).
  • Date.now() Returns the current timestamp in milliseconds. Subtracting start time calculates exact elapsed seconds accurately even if the browser jitters.
  • clearInterval(quizTimerId) Permanently stops the recurring interval when time reaches zero or the student submits.
db.collection("quizzes").doc(id).set(data, { merge: true })
Cloud Firestore SDK
Writes or updates documents in the Firestore database without overwriting existing fields.
const docReference = db.collection("quizzes").doc(quiz.orgId); await docReference.set(quiz, { merge: true });
Line-by-Line Explanation:
  • db.collection("quizzes") References the top-level quizzes collection in your Firestore cloud database.
  • .doc(quiz.orgId) Targets the specific document whose ID is the 6-digit room code (e.g. quizzes/482910).
  • .set(quiz, { merge: true }) Writes the quiz data to the cloud. The { merge: true } option updates existing keys safely without destroying unmodified fields.
visibilitychange, blur, fullscreenchange, contextmenu
Security & Anti-Cheat
Monitors browser events to detect candidate tab switches, focus loss, and window minimization.
// 1. Detect switching browser tabs document.addEventListener("visibilitychange", function() { if (document.hidden === true) { terminateAttempt("tab_switch"); } }); // 2. Detect leaving the window (Alt+Tab or clicking other app) window.addEventListener("blur", function() { terminateAttempt("window_blur"); }); // 3. Prevent right-click inspection menu document.addEventListener("contextmenu", function(event) { event.preventDefault(); terminateAttempt("context_menu"); });
Line-by-Line Explanation:
  • document.hidden === true Fires the exact millisecond a student clicks away to another browser tab or minimizes the window.
  • window.addEventListener("blur") Fires when the browser window loses system focus (e.g. opening a second monitor, calculator, or messaging app).
  • event.preventDefault() on contextmenu Cancels the default browser right-click popup menu to prevent copying question prompts or inspecting source code.
