0. What is app.js vs auth.js? Architecture

While auth.js handles identity, logins, and teacher overview analytics, app.js is the live exam runner. It executes solely on quiz.html to control the high-stakes test environment.

It handles dynamic DOM rendering of question choice cards, runs the attempt countdown timer, monitors tab switching / window blur events, saves answers in real-time to prevent data loss, grades the attempt against the answer key, and seals the final score in Cloud Firestore.

Viva Defense Tip: If an examiner asks: "Where does the exam actually run?" Say: "Sir, app.js runs the live assessment engine on quiz.html. It manages the runtime state, listens to browser security events, and handles auto-submission."

4. Anti-Cheat Engine (1-Strike Termination) Lines 241 – 298

armQuizAntiCheat(onViolationTerminateCallback) Lines 245 – 297

Monitors 5 distinct browser security events. Under our strict policy, any single violation invokes immediate termination.

Monitored EventBrowser Trigger & Code Hook
document.addEventListener("visibilitychange", function() { if (document.hidden === true) { handleViolationEvent("tab_switch"); } }); Tab Switching: Fires whenever the user switches to another browser tab or minimizes the browser.
window.addEventListener("blur", function() { handleViolationEvent("window_blur"); }); Focus Loss: Fires if user clicks on another monitor, opens Discord/Notepad, or uses Alt+Tab.
document.addEventListener("fullscreenchange", function() { if (!document.fullscreenElement) { handleViolationEvent("fullscreen_exit"); } }); Fullscreen Escape: Fires if student exits fullscreen mode (Esc or F11).
document.addEventListener("contextmenu", function(e) { e.preventDefault(); handleViolationEvent("context_menu"); }); Right-Click / Inspect: Prevents opening Developer Tools to inspect question data.
document.addEventListener("copy", function(e) { e.preventDefault(); handleViolationEvent("copy_attempt"); }); Clipboard Theft: Blocks copying question prompts to paste into ChatGPT or Google.
Viva Defense Tip: If the faculty asks: "Can a student open another window on a dual-monitor setup?" Answer: "No, sir. Because we listen to window.addEventListener('blur'), clicking anywhere outside the active browser window immediately fires a violation and terminates the exam."

function calculateStudentScore(questionsList, responsesMap, answerKeyMap) { let correctTotal = 0; for (let i = 0; i < questionsList.length; i = i + 1) { const questionId = questionsList[i].id; const studentChoice = responsesMap[questionId]; const correctChoice = answerKeyMap[questionId]; if (studentChoice !== undefined && correctChoice !== undefined) { if (Number(studentChoice) === Number(correctChoice)) { correctTotal = correctTotal + 1; } } } return correctTotal; }

6. Database Operations & Session Purge Lines 325 – 462

saveStudentDraft(...) & saveFinalQuizSubmission(...) Lines 329 – 436

Ensures fault tolerance and seals the exam:

  • saveStudentDraft(): Saves responses to both sessionStorage and Firestore. If the student accidentally reloads, progress is recovered.
  • saveFinalQuizSubmission(): Halts the timer (clearInterval), marks status as "submitted" or "terminated_cheat", computes final score, and commits to the database.
  • purgeStudentSession(): Sets sessionPurged: true and clears sessionStorage so the student cannot re-enter the room.
