How to Change QuizPulse Code During Your Viva

When an examiner says: "Open your VS Code and change X right now to prove you wrote it", stay calm! Here are the top 8 exact changes they typically request, where to find them, and how to change them in 30 seconds.

The Rule for Success: You don't need to be a senior programmer. You just need to know which file to open, press Ctrl + F to find the word, and change a number or a string.

1. Anti-Cheat Live Modifications

Task 1: "Disable anti-cheat temporarily so I can inspect elements" OR "Allow tab switching"
File: app.js
Examiner command: "Your anti-cheat terminates when I open inspect element or switch tabs. Turn that off right now so we can test it."
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: function armQuizAntiCheat (around line 215).
  3. Inside that function, find the event listeners for visibilitychange or blur, and simply comment them out by adding // at the start of the line!
Original Code
document.addEventListener("visibilitychange", handleVisibilityChange);
window.addEventListener("blur", handleWindowBlur);
Modified Code (Commented Out)
// document.addEventListener("visibilitychange", handleVisibilityChange);
// window.addEventListener("blur", handleWindowBlur);
What to say to examiner: "Sir, inside app.js in armQuizAntiCheat(), I commented out the event listeners for visibilitychange and blur. Now switching tabs will no longer terminate the exam."
Task 2: "Allow Right-Clicking / Enable Inspect Element"
File: app.js
Examiner command: "You disabled right click. Show me where you did that and allow me to right click."
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: contextmenu.
  3. You will see: document.addEventListener("contextmenu", handleContextMenu);
  4. Add // to comment it out!
Original Code
document.addEventListener("contextmenu", handleContextMenu);
Modified Code (Right Click Allowed)
// document.addEventListener("contextmenu", handleContextMenu);
What to say to examiner: "The contextmenu event is standard browser API for right-click. By commenting out its listener which had e.preventDefault(), right click is now enabled."

2. Timer & Duration Modifications

Task 3: "Change the default countdown timer or speed it up"
File: app.js
Examiner command: "We don't want to wait 10 minutes to test auto-submit. Make the timer 15 seconds instead."
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: function startAttemptTimer.
  3. Find: let remainingSeconds = totalSeconds;
  4. Change it to: let remainingSeconds = 15; (or whatever seconds they ask).
Original Code
function startAttemptTimer(totalMinutes, onTimeExpiredCallback) {
  let remainingSeconds = totalMinutes * 60;
  ...
Modified Code (Set to 15s)
function startAttemptTimer(totalMinutes, onTimeExpiredCallback) {
  let remainingSeconds = 15; // Set to 15 seconds for testing!
  ...
What to say to examiner: "In app.js, startAttemptTimer() initializes remainingSeconds. I overrode it directly to 15 seconds so we can see the auto-submission dialog immediately."

3. UI, Branding & Colors

Task 4: "Change the project primary color from green to blue or red"
File: teacher.html OR quiz.html OR index.html
Examiner command: "Change the whole site's primary theme color from green to blue."
  1. Open teacher.html (or index.html).
  2. Look right at the top of the <style> block at line ~15.
  3. Find: --accent: #245c3c; (the green color).
  4. Change it to blue: --accent: #2563eb; or red: --accent: #dc2626;
  5. Refresh the browser! All buttons, active tabs, and highlights will instantly update.
Original CSS Variables
:root {
  --accent: #245c3c;
  --accent-light: #e8f2ec;
  ...
Modified to Blue Theme
:root {
  --accent: #2563eb;
  --accent-light: #eff6ff;
  ...
What to say to examiner: "Because we used modern CSS3 Custom Properties (:root { --accent: ... }), changing the variable once automatically restyles all buttons, badges, and focus rings across the document without having to edit individual classes."

4. Grading & Passing Score Modifications

Task 6: "Add negative marking or change how scores are calculated"
File: app.js
Examiner command: "Currently you only give +1 for correct answers. Add -0.25 negative marking for wrong answers."
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: function calculateFinalScore (around line 280).
  3. Find the if (currentAnswers[i] === questions[i].correctOptionIndex) condition.
  4. Add an else block that subtracts 0.25!
Original (No Negative Marking)
for (let i = 0; i < questions.length; i = i + 1) {
  if (currentAnswers[i] === questions[i].correctOptionIndex) {
    score = score + 1;
  }
}
Modified (+1 for right, -0.25 for wrong)
for (let i = 0; i < questions.length; i = i + 1) {
  if (currentAnswers[i] === questions[i].correctOptionIndex) {
    score = score + 1;
  } else if (currentAnswers[i] !== null) {
    score = score - 0.25; // Negative marking!
  }
}
What to say to examiner: "Inside calculateFinalScore(), I added an else if (currentAnswers[i] !== null) check. If the student attempted an option but it's not the correct index, it deducts 0.25 points from their total."
Task 7: "Change passing criteria or show Pass/Fail on the results screen"
File: app.js
Examiner command: "Show whether the student PASSED (>= 50%) or FAILED (< 50%) when they submit."
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: renderSubmissionSummary.
  3. Find where the percentage is displayed: percentage.toFixed(1) + "%".
  4. Add a simple condition to display "PASSED" or "FAILED":
Original Code
let statusText = "Submitted Successfully";
Modified Code (Pass/Fail)
let statusText = "FAILED";
if (percentage >= 50) {
  statusText = "PASSED";
}
Task 8: "Show me where questions are rendered on the screen"
File: app.js
Examiner command: "Where does HTML create the question text and radio buttons?"
  1. Open app.js in VS Code.
  2. Press Ctrl + F and search for: function renderActiveQuestion (around line 90).
  3. Show them how document.getElementById("questionPrompt") updates the text, and the for loop generates the 4 option radio buttons using createElement("div").
What to say to examiner: "In renderActiveQuestion(), we extract the current question from the array, update the question number label, and loop through question.options to dynamically inject the choice cards into the DOM."
